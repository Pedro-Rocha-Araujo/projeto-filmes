## Tecnologias 🔧
* NextJS com Typescript
* Biblioteca React-toastify

## Funcionalidades ⚙️ 
* Listar filmes populares do momento
* Visualizar os detalhes dos filmes desejados
* Ser direcionado para o trailer do filme
* Adicionar e remover filmes da lista de favoritos

## Características 🧩
* 100% Responsivo para dispositivos móveis (mobile-first)
* Mensagens de Feedback para o usuário
